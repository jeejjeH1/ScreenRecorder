# Screen Recorder Pro 🎬

اپلیکیشن اندروید برای ضبط صفحه - طراحی شده برای تولیدکنندگان محتوا

## ویژگی‌ها
- ✅ دکمه بزرگ "شروع ضبط" در صفحه اصلی
- ✅ مجوز MediaProjection برای ضبط صفحه
- ✅ ضبط همزمان صفحه و صدای میکروفون
- ✅ نوتیفیکیشن + دکمه شناور برای توقف ضبط
- ✅ خروجی MP4 با کیفیت 1080p/30fps
- ✅ ذخیره خودکار در گالری

## ساخت
```bash
# با Gradle
./gradlew assembleDebug

# یا با ابزارهای SDK (بدون Gradle)
bash build.sh
```

## نصب
1. فایل APK را دانلود کنید
2. از تنظیمات گوشی، نصب از منابع ناشناخته را فعال کنید
3. نصب کنید

## مجوزها
- `RECORD_AUDIO` - ضبط صدا
- `FOREGROUND_SERVICE` - سرویس پیش‌زمینه
- `POST_NOTIFICATIONS` - نوتیفیکیشن (Android 13+)
- `SYSTEM_ALERT_WINDOW` - دکمه شناور
